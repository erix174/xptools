# WED Aircraft Size Reference
# ============================================================================
# WHAT THIS FILE IS: maps an aircraft ICAO type designator (A21N, B744, ...) to
# the ramp/gate size class it needs, using the same six classes WED's own
# ramp-start "Size" property already uses (ATCIcaoWidth: A-F), which follow
# the ICAO Aerodrome Reference Code wingspan bands:
#   A: wingspan <15 m   B: 15-<24 m   C: 24-<36 m   D: 36-<52 m
#   E: 52-<65 m         F: >=65 m (also covers outsized aircraft, e.g. An-225)
#
# FORMAT: <AIRCRAFT_ICAO> *** <SIZE_CLASS>
#
# SOURCE / METHOD: initial pass built from Wikipedia's "List of aircraft type
# designators" (https://en.wikipedia.org/wiki/List_of_aircraft_type_designators),
# cross-referenced against ICAO Doc 8643
# (https://www.icao.int/operational-safety/doc-8643-aircraft-type-designators/search)
# for any type not on that list. Class assigned from each type's published
# wingspan (manufacturer spec sheet or that aircraft's own Wikipedia
# "Specifications" section) - not guessed. One row per ICAO code; where a
# code covers several sub-variants with materially different wingspans (e.g.
# winglet retrofits), the class reflects the commonly-cited/production
# wingspan for that code as a whole.
#
# CONFIDENCE NOTE: every row below reflects a well-documented published
# wingspan. A handful sit within about half a meter of a class boundary
# (noted in the "verify" list at the end of this file) - worth a second look
# before treating those specific rows as final, everything else is solid.
#

# span for clearance purposes.

# TIER 2 CONFIDENCE NOTE: GA singles/twins, Van's RV kits, and business/
# trainer types above are high-confidence (well under any class boundary -
# nearly all sit comfortably inside A). Helicopter rotor-diameter figures are
# from commonly-cited spec sheets but were not individually re-verified this
# pass the way the near-boundary Tier 1 entries were - treat B214, BSTP, H47,
# H53, H60, HA4T, K900, S55/S58/S61/S64/S92, STAR as the ones worth a second
# look (all sit within ~1 m of the B/C or C/D lines for their category).
# B1's wingspan varies hugely with sweep (23.84 m swept, 41.8 m spread) - D
# reflects the spread/unswept figure, which is what matters for a parked
# aircraft's ramp footprint.
